# Project Hope identity

The new Project Hope mark was created with the built-in imagegen tool in generation mode. It is a raster PNG with a transparent background, used in the website header, footer, feature area, favicon metadata, and desktop app.

Final website asset: `public/hope-mark.png`.
Social-sharing artwork: `public/images/social-card.png`.
The desktop installer uses a 512-pixel PNG derivative of the same mark; only delivery sizing and format conversion were applied, not a redraw.

## Final logo prompt

Use case: logo-brand

Asset type: production website and desktop app logo for Project Hope, a warm, capable charity workspace.

Primary request: design a distinctive, premium original brand symbol that combines a welcoming open doorway, an abstract H, and two rounded forms supporting one another. It should suggest optimism, care, and quiet confidence without looking like a hospital, church, generic heart charity logo, or technology circuit.

Style/medium: exceptionally simple flat vector-like logo rendered as a crisp raster asset. Bold sculptural silhouette, subtly softened geometric curves, balanced intentional negative space, recognisable at favicon size.

Color palette: deep forest green #193e31 with one small muted terracotta #bc553c accent. Match a warm ivory and sage website.

Composition/framing: ONE centered standalone symbol, square canvas, generous but not excessive margin, mark fills roughly 78 percent of the canvas.

Scene/backdrop: genuinely transparent background with alpha.

Constraints: no words, no letters written separately, no tagline, no mockup, no border, no gradients, no drop shadows, no 3D, no watermark, no multiple variants. Original design, no existing brand trademark.
