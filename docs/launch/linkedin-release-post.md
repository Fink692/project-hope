# LinkedIn release post — Project Hope 1.7

## Post

After a long stretch of building, testing, rebuilding, and caring about the details users should never have to think about, I’m incredibly proud to release Project Hope 1.7. 🌱

This is a major trust release for a simple experience: provision a managed workspace, install the app, sign in, and get to work.

Charities do essential work, but too many are still asked to stitch that work together with disconnected spreadsheets, inboxes, documents, and tools that assume an IT team is standing by.

Project Hope brings contacts, volunteers, schedules, documents, grants, communications, impact work, accessibility tools, and carefully bounded AI into one connected workspace.

Version 1.7 protects that first day—and every sign-in after it:

- ✅ Built-in authenticator-app two-step verification on browser and mobile
- ✅ A guided QR setup, manual key fallback, and recovery codes shown once
- ✅ Single-use password challenges, replay protection, and one-time recovery codes
- ✅ Password or security changes automatically revoke older sessions and app tokens
- ✅ Operator-safe recovery and encryption-key rotation without exposing secrets
- ✅ Secure invitations, role controls, account recovery, and connected desktop/web/mobile access

The part I’m proudest of is not a single feature. It is the care underneath them: a charity should not need to understand containers, databases, model runtimes, or deployment architecture just to use good software.

This release passed 57 backend tests, 13 web journeys with automated accessibility checks, 7 AI-gateway tests, production builds across every client, dependency audits, migration checks, and fail-closed production configuration checks.

I’m now opening the Founding 10: ten charities willing to test Project Hope honestly and help shape what comes next. The planned managed Founding Partner pilot is CAD $149/month after the workspace is live. There is no application fee, no card collected to apply, and no payment obligation until scope and responsibilities are agreed in writing.

If you work with a charity—or know someone who does—I would be grateful if you shared this.

To ask about a Founding 10 place, send me a private LinkedIn message with “FOUNDING 10” and your charity’s name. Please do not post personal, client, donor, volunteer, or service-user information in the comments.
