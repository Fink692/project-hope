# Project Hope 1.4.0 — Local AI that is actually ready

Project Hope 1.4 adds a real, charity-controlled local model runtime while keeping the safety behavior that makes the platform usable without AI.

## What ships

- Ollama is included in the local and production Compose topologies.
- The default stack prepares `qwen3:4b` for bounded text generation and `all-minilm` for semantic embeddings.
- Classification, email drafting, translation, plain-language rewriting, evidence-grounded grant answers, and embeddings use the configured local models when ready.
- Model readiness is visible from the AI gateway health endpoint and the Project Hope welcome screen.
- Deterministic fallback behavior remains available if a model is still downloading, unavailable, or too large for the host.
- Crisis terms bypass the language model and force human transfer handling.
- Model/provider provenance is stored on workflows for audit and review.
- Gateway unit tests, live Ollama smoke checks, backend tests, web tests, builds, lint, and type checks pass.

## Setup note

The first Compose setup downloads the configured models into the private Ollama volume. This can take several minutes and needs several gigabytes of free disk space. No AI account or paid API key is required.

OCR, speech recognition, speech synthesis, telephony, and identity federation remain separate operator-owned integrations because they require host runtimes, hardware, phone service, or organization policy beyond a text-model download.
