# Project Hope 1.2.0 — One workspace, every device

Project Hope 1.2 turns the product into the experience people expect from a normal app: install it, sign in, and work in the same connected workspace everywhere.

## What ships

- Installable standalone desktop web app for Windows, macOS, and ChromeOS.
- Existing iPhone and Android Expo client aligned to the same hosted workspace.
- In-app “Install the app” entry point with browser-aware install behavior.
- Plain-language distribution guide for charity teams and their setup partners.
- A single-source-of-truth model: one hosted API, one organization boundary, one backup/update path.
- Release metadata aligned to 1.2.0 across web, mobile, API client, OpenAPI, and Expo.

## The charity experience

Staff open one secure address or download the mobile app. They sign in once and see the same charity workspace on desktop, iPhone, and Android. They do not install Docker, configure a database, manage backups, or keep separate copies of records.

## Quality signals

- Web tests, production build, API-client TypeScript, mobile TypeScript, Expo export, and Expo Doctor all pass.
- GitHub Actions validates backend, web, mobile, Compose, production configuration, onboarding helpers, and release tags.
- The PWA manifest uses standalone display mode, with a browser install prompt where supported and plain-language fallback instructions elsewhere.

## The one operator-owned step

A hosting/setup partner deploys the production workspace once, configures its domain, HTTPS, MFA, email, backups, and Apple/Google signing credentials. After that, charities receive download links and a normal app-like experience.
